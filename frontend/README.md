# E2E Backup — Frontend

React + TypeScript + Vite + Tailwind + shadcn/ui

## Setup

npm install
npm run dev

Opens at http://localhost:5173

## Stack

- React 18 + TypeScript
- Vite
- Tailwind CSS v4
- shadcn/ui (Radix)
- Axios
- React Router v6
- React Hot Toast

## Structure

src/
├── api/         # API calls (auth, snapshots)
├── components/  # Shared components + shadcn/ui
├── hooks/       # useAuth
├── pages/       # LoginPage, RegisterPage, DashboardPage
